# Reviewers Start Here

Commons Unified Protocol is an experimental signed-message format for bounded communication between approved nodes.

## Review focus

Verify canonical serialization, signature coverage, key allow-lists, nonce uniqueness, replay rejection, key rotation, downgrade handling, and failure behavior.

## Evidence boundary

The protocol is experimental. It is not a production security standard or proof that participating systems are aligned.

Read [SECURITY.md](SECURITY.md) and [CODEOWNERS](.github/CODEOWNERS) before testing.
