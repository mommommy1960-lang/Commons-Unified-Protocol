## How to Contribute

Contributions to the Commons Unified Protocol are welcome and must comply with:

1. **CERL-1.0 License:** All contributions are licensed under CERL-1.0
2. **Chain of Custody:** Maintain provenance documentation for all changes
3. **Constitutional Alignment:** Ensure contributions align with protocol values
4. **Code Review:** All contributions require review and approval

For contribution guidelines, see the project README and provenance documentation in `docs/provenance/`.

---

## Recognition Policy

Contributors are recognized based on:
- **Substantive contributions** to code, documentation, or architecture
- **Ongoing stewardship** of protocol components
- **Community alignment** with CERL and protocol values

Recognition does not transfer ownership rights, as all work remains in the commons under CERL-1.0.
